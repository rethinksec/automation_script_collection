# Automation Collection Scripts

This repository contains the scripts that can be used for quick setup for automation or extend the capabilities to be as part of any SOAR projects.

Just rename config-sample.yml to config.yml & insert your respective API key then you are good to go!

## Currently includes

- VirusTotal
- IP Quality Score (IPQS)

## Planned includes

- Any open-source security solutions that have in mind
- Any close-source (but trial available) solutions that have in mind
